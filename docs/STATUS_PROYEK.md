Dikonfirmasi test ini benar-benar mendeteksi bug: di-`git stash` sebentar untuk menjalankan tanpa fix → 2 gagal dengan mismatch persis (`opacity/transform`, `width`) yang dilaporkan; fix dikembalikan → **5/5 lulus**. `npx tsc --noEmit`: bersih. `eslint` (scope: 2 file yang diubah — `npm run lint` tanpa scope saat ini ikut memindai `.next-stack/**`/`.next-ui/**`, build cache gitignored dari test run sebelumnya yang belum masuk `globalIgnores`; gap pra-eksisting, di luar scope bug ini, tidak disentuh): bersih.
